# 个人辅助回复（0.10.0）

适用于只有个人抖音账号、没有开放平台应用或接口授权的使用者。此模式不访问抖音页面、不读取真实评论接口、不自动发布。评论由用户手动导入，回复复制后由用户在抖音自行发布。

## 使用步骤

1. 打开本地工作台，点击“个人辅助回复”。首次进入会保存为默认入口，以后刷新或重启保留。
2. 到“模型连接”保存并测试模型。支持已有云模型和本机Ollama等；云模型需要有效Key，会收到导入的评论和用于回答的资料。
3. 返回个人页面，填写作品名称、完整作品链接、模型、已确认的正文/背景，可选知识库，点击“保存作品与资料”。链接仅用于本机归档，不代表程序读取了作品；短分享链接请先自己打开并复制含video/note/modal_id的完整地址。
4. 粘贴评论导入，或导入不超过1MB的TXT/TSV/JSON，一次1～200条。纯文本每行一条，昵称与正文可用Tab分开；多行正文可用JSON导入。
5. 单条生成或勾选最多20条生成草稿，核对后编辑并保存。缺少可用资料或Key时不伪造回复，错误显示在记录中。
6. 点击“复制已保存回复”，到抖音自行发布。复制成功只登记“已复制”，不会标记发送成功。剪贴板不可用会选中文字供手动复制，但不会登记复制成功。
7. 只有实际发布后，再点击“我已在抖音手动发布”并确认。记录为“人工确认已发布（未核验）”，不会冒充官方返回的发送成功；确认后的文字作为快照保留，不允许直接重新生成或编辑这条记录。

## 导入格式

TXT/TSV每行：`昵称<Tab>评论正文`，或只有评论正文。

JSON示例：

```json
[
  {"author":"用户甲","text":"请问怎么办？","commentId":"可选的评论ID"},
  {"author":"用户乙","text":"感谢分享"}
]
```

有评论ID时按作品+ID去重；没有ID时按作品+昵称+正文去重，相同昵称相同正文的不同评论可能合并。仅复制昵称、正文和必要ID即可，不要导入密码、Cookie或用户不必要的私人信息。

## 历史与边界

评论按作品隔离，来源标记为手动导入，不能通过官方发送API提交。切换到官方监听也不会把个人草稿当成历史基线改写。复制次数、最后复制文本、操作时间和人工发布文字快照存入本机SQLite，每条最近50条复制/发布事件可在记录中展开查看，完整记录可使用现有历史查询/导出和备份。

页面每次展示最近200条，可按待生成/草稿/失败/已复制/人工发布筛选。未保存编辑不会被刷新悄悄覆盖；复制前必须保存。人工确认不验证抖音页面，不会自动删除或撤回已发布的评论。

`npm run test:personal` 使用隔离数据与真实本地HTTP模型夹具，验证无官方授权导入、去重、缺资料拒绝生成、编辑/复制/人工发布、禁止API发送、跨作品保护和重启保留。没有访问抖音或发布真实评论。真实云模型效果需用用户自己的连接验证。本轮不打包。
