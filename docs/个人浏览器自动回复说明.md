# 个人浏览器自动回复（0.11.0）

无需开放平台应用即可选择浏览器操作，但这不代表取得官方接口授权。抖音用户协议限制自动化访问和处理，账号可能遇到验证或限制。请自行核对[平台协议](https://www.douyin.com/draft/douyin_agreement/douyin_agreement_user.html?id=6773906068725565448&ug_source=hd_xzzj)。程序不绕过验证码，不重放私有接口。

## 使用步骤

1. 在个人模式保存自己的作品完整链接、作品资料、模型连接及可选知识库。模型需配置有效 Key，或者连接可用本地模型；缺少已确认事实时不会生成。
2. 点击“启用浏览器自动模式”。填写当前登录账号的准确昵称，设置检查间隔（最低10秒）、每日上限，选择“生成后自动发送”，点击“保存自动设置”。
3. 点击“打开登录浏览器”，在新窗口手动扫码登录，核对目标作品并展开评论区。普通浏览器的登录状态不会自动共享。
4. 勾选本人账号及作品归属，点击“确认账号和当前作品”，再点击“启动监听回复”。随后让其他账号发表一条新测试评论。
5. 工作台显示评论、模型生成内容、发送状态和错误；需要停止时点击“暂停”。

## 行为和边界

- 启动时建立时间起点，已有评论跳过；只有具有稳定标识且发布时间明确晚于起点的新评论才处理。自己的评论跳过，避免自我回复循环。
- 本版浏览器模式一次监听一个作品；官方模式的多作品调度不等于浏览器已支持并行。仅处理当前页面可加载的评论，高评论量可能漏读，不承诺全量实时。
- 检查默认10秒，读取、生成、发送依次执行；模型耗时和页面加载会增加回复延迟。浏览器发送间隔至少3秒，每日限额按已有发送、发送中及结果不明记录保守计算。
- 发送前核对原评论标识、作者、正文；发送后在原评论内核对新增的精确回复。无法确认结果则暂停，先人工检查，不能直接重发。
- 登录失效、验证码、页面定位失败会暂停。重新打开浏览器或重新确认账号后需要重新启动、建立新起点；暂停期间的评论不自动补发。服务重启不自动开启浏览器或发送。
- 账号归属由用户核对确认，不能自动证明作品所有权，也不能可靠识别用户在页面中自行切换账号。切换账号前先暂停并重新确认。
- 浏览器资料在本机数据目录 `browser` 下，包含登录状态，请勿分享。手动导入与复制发布功能仍保留，与浏览器记录隔离。

## 验证情况

79项单元测试及个人手动模式、官方界面、浏览器定位回归通过。`npm run test:personal-browser` 使用隔离数据库、本地模型服务和合成抖音页面验证：新评论自动生成并通过DOM发送、旧评论及本人评论跳过、验证码暂停、重启不重发。真实抖音页面及真实模型仍需扫码后联调，页面变化可能需要校准选择器。
