# CommentPilot 0.2.1

## 本地模型不用再手填

启动后自动检测本机 Ollama，在“模型连接”里点击“使用本机模型”，从下拉列表选择并保存。无需 Key，不用填写接口、协议或模型名称。修改过端口的用户可在高级设置填写地址，再重新检测。

模型能力通过 Ollama 元数据确认，向量等不支持文本生成的模型不会放入回复列表。旧版服务没有能力元数据时保留兼容，由连接测试确认是否可生成。未连接服务、没有对话模型和读取失败分别给出提示。

## 配置自动保留

保存的本地和云端模型都进入 SQLite 数据库。下次打开直接选择已有连接，无需重新配置；云端 Key 仍采用 Windows 用户级加密。保存后保留当前编辑项，再次保存会更新该连接，避免误新增重复项。

常用页面只显示供应商、模型、必要的 Key 和保存选项；连接名称、地址、协议、认证、超时与 token 上限收进高级设置。本地模型默认不显示 Key 输入。

## 工作台布局

顶部为配置和运行两张等宽卡片；评论占据下方整行，内容过长时在评论区滚动。作品背景、图片文字与日志折叠展示，避免长期只有右侧很长。模型管理使用保存列表与配置表单两栏；历史筛选在桌面采用网格布局，窄屏自动调整。
