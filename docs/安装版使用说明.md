# CommentPilot 0.3.0 使用说明

运行 `CommentPilot-Setup-0.3.0-x64.exe`，安装后打开 CommentPilot。无需单独安装 Node.js、浏览器或数据库。免安装版本请保留完整程序目录，不能单独复制 EXE。

## 1. 配置模型

打开“模型连接”，选择供应商，填写连接名称、基础地址和模型名称。云端服务填写 API Key，本机 Ollama / LM Studio 通常选择无需认证。模型必须已由供应商开通或在本地服务加载。

Ollama 用户：先启动本机 Ollama。CommentPilot 会自动检测已安装模型，点击“使用本机模型”，下拉选择后保存即可，无需 Key、无需手填模型名。向量等非对话模型会自动略过。保存的模型连接会保留，重启可直接使用。修改过本机端口时展开高级设置填写地址，再点击重新检测。

云端用户：选择供应商，填写 Key 和模型名，地址与协议默认已填好；需要自定义地址、超时或连接名称时再打开高级设置。

同一家厂家的其他型号：可以直接编辑型号；如果要保留多个型号，在已保存连接上点“同厂家新增型号”，填入新型号或点“读取厂家模型列表”选择，再保存。相同厂家和地址可复用原 Key，每个型号是独立连接，作品绑定互不覆盖。

智谱：选择“智谱 GLM”，填写标准模型 API Key 和控制台中的准确型号，保存并测试。地址已预填，无需另选协议。套餐 Key 与标准 API Key 不通用；如服务不提供模型枚举接口，可手动填写准确型号，不将空列表当作型号不可用。

## 多作品与知识库

1. 在“知识库”输入已确认的资料，或导入 UTF-8 `.txt` / `.md` 文件，再保存。每次保存形成新版本。
2. 在“作品管理”新增具体作品链接和便于识别的名称，选择回复模型、知识库及本作品补充资料，保存。
3. 点击“使用此作品”返回工作台，连接并核对后启动监听。当前一次监听一个作品；切换前暂停。多个作品的模型、补充资料和知识库分别保存。
4. 作品卡片的“评论历史”仅查看这个作品的记录，不改变当前监听作品。

已绑定知识库时，生成依据知识库、作品正文、已核对 OCR 和本作品补充资料。未绑定时使用本作品资料；完全没有资料时拒绝生成。知识库或正文冲突、缺少答案时要求模型说明无法确认，不猜测金额、日期和承诺。每次生成记录保存当时知识库版本和实际上下文快照。资料变更后旧草稿需重新生成，避免按过期资料发送。

知识库全文最多30000字符，支持一个知识库复用到多个作品。当前没有向量检索、PDF/Word 文件解析或多作品同时监听；约束与资料隔离降低幻觉风险，仍需核对关键业务回复。

保存并点击“测试”。设为默认的连接会用于后续评论生成；已有回复历史保留生成时使用的模型信息。OpenAI / Codex API 使用具备对应模型权限的 API Key，不使用 Codex 客户端或 CLI 的订阅登录。

阿里百炼地址和 Key 需要同地域；支持填写控制台提供的业务空间地址。推理模型返回空内容或截断时，可提高最大输出 token。超时可在连接设置修改。

Key 加密保存在当前 Windows 用户下，重启无需重复输入。输入框留空表示保留；勾选删除 Key 后保存表示清除。Key 不显示明文，也不会进入普通历史导出。

## 2. 连接作品并回复

在“工作台”粘贴抖音作品链接，选择模型连接，点击“连接作品 / 登录”，在程序浏览器内扫码。作品正文会自动提取；图片文字使用“识别图片文字”，核对后采用。高级设置可以补充作品之外的资料和回复口吻。

确认账号昵称和作品正确。未勾选自动发送时，只生成草稿；勾选后，新评论会生成并提交回复。点击“启动监听”会记录已有评论作为历史，只处理启动后发布的新评论。“继续上次监听”会从旧起点检查，包括暂停期间的新评论。

默认 10 秒检查一次。页面加载、模型生成和抖音提交还需要时间。请保持程序和专用浏览器打开。验证码、登录失效由用户处理。发送结果不明时程序暂停，需要在抖音核实，不会自动重复发送。

## 3. 查历史和备份

“历史记录”可按作品 ID、关键词、时间、模型/供应商和状态筛选；详情展示评论、模型调用、背景快照、用量、耗时及发送结果。生成成功和发送成功分开记录。可导出当前筛选的 JSON 或 CSV。

“设置”可以创建 SQLite 一致性备份，界面显示备份路径。备份包含加密 Key，但只有原 Windows 用户可以解密；迁移到其他机器后重新填写 Key。

新用户数据在 `%APPDATA%\CommentPilot`。若检测到旧版 `%APPDATA%\DouyinReplyWorkbench`，沿用旧目录并自动导入旧 JSON；原文件和迁移备份保留。开发版数据在项目的 `data` 下，不自动与安装版混合。旧版内存中的 Key 需要首次在新版保存。

恢复备份：先退出所有使用该数据目录的程序，备份整个原目录，将目标备份复制为 `commentpilot.sqlite`，移走原有对应 `-wal` / `-shm` 文件后再启动。不要在运行时替换文件。浏览器登录资料在独立 browser 子目录，数据库备份不包含登录资料。

## 4. 常见问题

- 401：检查 Key、供应商和地域；403：检查模型权限；404：检查基础地址、协议及模型名。
- 本地连接失败：先启动本地模型服务并加载模型，再检查端口。
- 评论没有发送：先看是否只生成草稿、是否历史跳过、账号昵称是否正确，再查看历史详情和运行日志。
- 不确定发送结果：进入抖音人工核实，不要直接反复点击发送。
- 安装包未签名，Windows 可能展示发布者提示。

当前版本没有完整遍历历史分页或转写视频语音，高流量情况下可能存在未加载评论。
