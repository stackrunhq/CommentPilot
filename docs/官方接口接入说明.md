# CommentPilot 官方接口接入

当前源码默认通过官方 API 读取和发送评论，不使用浏览器扫码登录、DOM 选择器或 Cookie。旧浏览器代码仅为隔离回归测试保留，不在权限失败时回退使用。已发布 0.3.0 安装包尚未替换。

## 管理员准备

需要抖音开放平台审核通过的移动/网站应用，申请 `user_info`、`video.list` 及获批的 `item.comment` 或 `video.comment`。企业评论接口要求授权用户是企业号。仅有 `ma.item.comment` 的小程序不能直接套用本实现。申请是否获批和图文作品是否支持，需要以应用控制台与平台验证为准。

在启动后端的进程中配置以下环境变量（不提交到仓库、不写入安装包）：

- `DOUYIN_CLIENT_KEY`：应用标识。
- `DOUYIN_CLIENT_SECRET`：应用密钥。
- `DOUYIN_REDIRECT_URI`：平台批准并登记的回调地址。
- `DOUYIN_SCOPES`：实际获批并需要申请的权限，默认 `user_info,video.list,item.comment`。企业接口应用可设置 `user_info,video.list,video.comment`。

然后 `npm start`。环境变量由当前启动进程继承；换终端或重启方式后需确保仍有管理员配置。不要把密钥发到聊天或截图中。

回调可在平台允许并登记的情况下设置为 `http://127.0.0.1:3210/oauth/douyin/callback`。若平台不接受本机回调，使用自己控制的 HTTPS 回调；当前开发版可将授权后的完整回调地址复制到工作台的“完成授权”输入框，按一次性 state 校验换取令牌。复制包含临时凭据，仅粘贴到本机应用，不提供给第三方。生产分发需建立受控的服务端授权代理和回调交接，**该代理本轮未实现，不应把共享 Client Secret 下发给所有安装用户**。Electron 安装版随机端口也应通过代理交接，不能假设固定 3210 回调适用。

## 用户操作

1. 配置模型并测试。
2. 点击“抖音授权”，打开生成的官方授权链接并完成授权。
3. 点击“读取官方作品”，从已授权账号返回的列表选择作品。网页数字 ID 不会直接充当官方加密 item_id。
4. 为作品绑定知识库或填写已确认的补充资料；官方列表当前只导入标题。
5. 启动监听。已有评论不补发；无评论可正常建立基线。只有启动后确认发布时间的新评论进入模型队列。
6. 默认生成草稿，启用自动发送才会提交。自动发送受每日上限和官方额度约束。现有检查间隔沿用工作台设置，管理员应按获批额度调整；HTTP 429 会暂停并冷却，不能保证任意频率或实时性。

切换授权账号后必须重新启动监听，旧账号或浏览器监听不能恢复。清除本机授权只删除本机令牌，不等于平台撤销授权；平台撤销需到抖音授权管理操作。

## 自动判断身份和接口

程序读取 OAuth 返回的实际 scope，优先 `item.comment`，否则使用 `video.comment`；没有对应权限明确报错，不要求用户勾选个人/企业。`user_info` 的公开示例包含 `e_account_role`，但文档未给出足够可靠的完整身份枚举，因此当前身份展示“未知”，保留原始角色在加密记录中，不把空字段或缺权限猜成个人号。企业权限也不能替代平台对账号资格的校验。

## 内容提取与准确率

当前从官方作品列表读取发布文案的 `title` 字段，可能不完整。封面不能代表整套图片或完整视频；不宣称官方评论接口提供原图、动图全部帧、原视频、字幕或转写。当前官方路径不执行原有浏览器 OCR 下载流程。

0.5.0 已支持在“文案与素材”导入自己的原文件：静态图 OCR、动图/视频定时抽帧去重、内嵌文本字幕提取、可选语音转写和视觉模型画面理解，并保存时间位置和抽样提示。素材获取与识别分开，不能仅凭作品链接自动取得所有原文件。长视频若仅 OCR 会漏掉口述和无字幕画面。模糊、遮挡、滚动字幕、方言和小字号均会产生错误；OCR 引擎置信度不是实际准确率，不能承诺任意作品均高准确。金额、日期、政策等关键事实应核对后再进入回复依据。具体用法见[文案与素材识别说明](文案与素材识别说明.md)。

## 实现和验证边界

- `douyin-official.js`：OAuth state、令牌刷新、DPAPI 加密存储、权限路由、官方作品映射、分页和回复。
- `server.js`：复用模型、知识库、SQLite 历史、启动基线、自动队列和每日上限。官方评论 ID 独立命名空间，支持加密字符串 ID。
- 发送必须取得官方返回的回复 ID 才标记成功。网络超时或未返回 ID 标记 `uncertain` 并暂停，绝不自动重发；本轮未实现结果不明任务的自动查询核验。
- 列表页超过分页上限或出现重复游标会停止，不接受不完整历史基线。当前每轮读取完整评论列表，上限 50 页、每页 20；大量评论作品需后续增量扫描设计，当前超过上限会明确报错。
- `npm test`、`node test-official.mjs`、`node test-official-flow.mjs`：协议模拟、无授权工作台、隔离的授权/加密/生成/发送/重启去重/发送超时。测试未调用真实抖音或真实模型。完整流程的 DPAPI 需在正常 Windows 用户环境执行。

真实应用权限、真实账号、原图文作品兼容性、生产授权代理和新版安装包均尚未验收。媒体识别已通过本地生成素材验证，真实中文长视频与真实视觉/语音供应商仍需实测，不宣称完整无遗漏或准确率保证。
