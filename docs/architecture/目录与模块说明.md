# 目录与模块说明

本次为 0.5.0 源码结构整理，功能和运行数据位置保持不变。本地 Git 标签 `source-layout-before` 与 `source-layout-after` 分别记录整理前后源码，逐文件迁移清单见 [source-migration.json](source-migration.json)。

```text
CommentPilot/
├─ src/
│  ├─ app/          后端入口、配置校验、应用与界面路径
│  ├─ comments/     评论标识、基线、持久队列、分批扫描和发送核验
│  ├─ works/        作品链接识别、内容提取、回复背景合并
│  ├─ knowledge/    知识库约束、资料引用、上下文指纹
│  ├─ models/       模型供应商适配、发现与回复生成
│  ├─ storage/      SQLite、数据迁移、历史与备份
│  ├─ security/     Windows DPAPI 凭据加解密
│  ├─ observability/ 脱敏结构化日志、操作追踪与诊断导出
│  ├─ douyin/       抖音官方 OAuth / OpenAPI
│  │  └─ browser/  旧浏览器适配，供隔离回归夹具使用
│  ├─ media/        素材导入、OCR、抽帧、字幕、语音/视觉适配
│  ├─ desktop/      Electron 主进程和后端生命周期
│  └─ ui/           网页、样式及 scripts/ 下的前端功能脚本
├─ tests/
│  ├─ unit/         单元测试
│  ├─ integration/  工作台、作品、素材、官方接口等集成测试
│  └─ fixtures/     模拟官方接口夹具
├─ scripts/
│  ├─ dev/          开发后端重启
│  ├─ verification/ 桌面入口验证、旧数据迁移验证
│  └─ release/      暂存、打包产物核验、安装验证（本轮未运行打包）
├─ config/          Electron Builder / NSIS 配置
├─ docs/            用户说明、架构、方案与验收记录
├─ data/            本地用户数据，不进入 Git
├─ release/         历史安装包和测试产物，不进入 Git
├─ node_modules/    依赖，不进入 Git
├─ README.md        使用与开发入口
├─ CHANGELOG.md     功能与结构变更记录
└─ CONTINUATION.md  开发续接状态、已验证结果、待办
```

## 主要入口

| 需求 | 文件 / 命令 |
| --- | --- |
| 启动后端 | `npm start` → `src/app/server.js` |
| 重启后端 | `npm run restart` → `scripts/dev/restart-backend.ps1` |
| 启动桌面客户端 | `npm run desktop` → `src/desktop/main.cjs` |
| 官方授权/评论接口 | `src/douyin/official.js` |
| 模型接入 | `src/models/providers.js` |
| 回复规则/提示词 | `src/models/reply.js` |
| 数据表/历史/备份 | `src/storage/database.js` |
| 素材识别任务 | `src/media/service.js` |
| 前端页面/交互 | `src/ui/index.html`、`src/ui/scripts/` |
| 后端根路径 | `src/app/paths.js`，不根据源码所在目录另建 data |

原 `lib.js` 的作品链接函数迁入 `src/works/identity.js`；评论 hash 迁入 `src/comments/identity.js`；配置校验迁入 `src/app/config.js`；生成回复迁入 `src/models/reply.js`。没有保留根目录转发文件，以免出现两套实现。

`src/app/server.js` 目前仍负责路由和任务编排，本轮没有大幅改写流程。后续如继续拆路由，应保持作品隔离、发送去重、上下文检查和暂停机制，不在目录整理中顺便改变业务行为。

## 本地回溯

仓库只在本机建立，没有配置或推送远程。源码、测试、配置及文档纳入 Git；用户数据库、媒体文件、模型密钥、登录资料、依赖和安装包排除。

```powershell
git log --oneline --decorate
git diff source-layout-before source-layout-after --stat
git show source-layout-before:lib.js
git show source-layout-after:src/models/reply.js
```

当前机器 PATH 中 `git` 优先命中失效的 depot_tools/git.bat，如命令失败，使用：

```powershell
& 'C:\Program Files\Git\bin\git.exe' log --oneline --decorate
```

查看历史不需要回滚整个工作区。若要实际切换旧版本，应先停服务并保留未提交代码；Git 不备份用户数据库，数据库恢复仍使用 `data/backups`。

后续每项功能至少更新 `CHANGELOG.md`（改变什么、影响、验证）和 `CONTINUATION.md`（当前状态、未完成事项），完成后提交本地 Git。不得把凭据或运行数据加入提交。
