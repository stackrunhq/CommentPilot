# CommentPilot 执行规划

后续改进：已完成 [0.2.1 本地模型自动发现与界面调整](CommentPilot-0.2.1更新说明.md)。

更新日期：2026-10-16。状态：本轮实施及安装包验证已完成，版本 0.2.0。

## 1. 目标与执行约定

将现有抖音评论助手升级为 CommentPilot：可安装的 Windows 桌面程序，支持多家云端模型及本地模型，使用数据库持久保存配置、加密凭据和评论回复历史。

用户已授权按此范围持续推进。常规代码修改、依赖选择、数据库迁移、测试、构建及安装包验证直接执行，不逐项索要确认。需要用户实际扫码、处理验证码、提供缺失凭据或决定无法兼容的业务行为时，集中说明具体阻塞；其余工作继续。真实账号发送沿用用户在工作台选择的自动发送设置，测试默认使用隔离数据和模拟评论。

不将“实现完成”与“所有供应商真实联调完成”混为一谈：缺少某供应商凭据时，完成协议测试、配置及错误处理，单独标记真实联调待验证。

## 2. 产品范围

- 项目、窗口、页面、快捷方式、使用说明统一为 CommentPilot；npm 包名使用 commentpilot。
- 程序名 CommentPilot.exe；安装包 CommentPilot-Setup-<版本号>-x64.exe；构建产物放入 release。
- 模型连接可新增、编辑、删除、测试、设为默认；保存连接名称、供应商、接口地址、模型名称、认证方式、超时和必要生成参数。
- 首批支持 DeepSeek、阿里云百炼、OpenAI、Ollama、LM Studio、vLLM，以及自定义 OpenAI 兼容服务。
- 不把“支持各种模型”解释为所有服务共用一种请求格式。通过适配器支持 Chat Completions、Responses 和 Ollama 协议；未适配协议明确提示。
- Codex 需求先支持供应商实际开放、当前账户可访问的 API 模型；实现前核对官方文档。Codex 客户端、CLI 和订阅登录是另一种集成，不假设订阅等于 API 授权，不读取客户端私有凭据。若需要额外独立适配，记录到后续任务，不阻塞其余功能。
- SQLite 本地数据库；提供跨作品历史查询、分页、详情、统计和导出。
- 保留自动读取作品、OCR、10 秒轮询、仅回复新评论、稳定 ID 去重及发送结果核验。

## 3. 技术结构

继续使用 Electron + Node.js + Playwright，避免无必要重写。

建议拆分：

| 模块 | 职责 |
| --- | --- |
| storage / migrations | SQLite 初始化、版本迁移、事务、备份 |
| repositories | 配置、连接、作品、评论、调用、回复和监听数据访问 |
| credentials | Windows 用户级加密、密钥掩码、解密及替换 |
| providers | 不同模型协议适配、请求验证和统一输出 |
| reply service | 上下文构建、模型调用、回复状态流转 |
| browser / polling | 评论发现、原评论定位、发送和结果确认 |
| history API | 筛选、分页、详情、统计和导出 |

数据库驱动先验证 Node 开发环境和 Electron 实际子进程是否支持内置 node:sqlite；满足打包兼容要求则优先使用。否则选择经过 Electron ABI 验证的 SQLite 驱动，并加入构建检查，不只验证开发环境。

模型统一结果包含：文本、供应商、连接 ID、实际模型、耗时、token 用量和请求标识。不同模型缺失用量时显示未知，不能记为零。暂不自动切换供应商，避免意外费用及上下文发送到其他服务。

## 4. 数据设计

| 表 | 主要内容 |
| --- | --- |
| schema_migrations | 已执行的数据库版本 |
| app_settings | 默认连接、轮询及发送设置 |
| model_connections | 供应商、地址、模型、参数、凭据引用、启用状态 |
| credentials | 加密后的 API Key、加密方案版本、更新时间 |
| works | 平台、作品 ID、链接、作者、正文、补充背景 |
| work_content_versions | OCR 原文、核对结果、来源和上下文版本 |
| comments | 作品 ID、平台评论 ID、作者、正文、发布时间、首次发现时间、状态 |
| model_calls | 评论及连接引用、脱敏请求上下文快照、响应文本、用量、耗时、错误 |
| reply_attempts | 生成内容、最终发送内容、提交与确认时间、发送结果及错误 |
| monitor_sessions | 作品、起始时间、历史基线、监听状态 |
| events | 关键操作和状态变化，不包含凭据 |

作品 ID + 平台评论 ID 建唯一约束；常用作品、时间和状态查询建索引。模型调用和发送尝试分别记录，支持同一评论多次人工生成但不重复自动发送。记录模型与连接的历史名称快照，后续改名不改变历史含义。时间统一存储 UTC，界面按本地时间显示。

API Key 加密后入库，不以明文进入日志、模型调用快照、历史导出、安装包或 HTTP 响应。界面只返回掩码和“已配置”状态；支持替换、删除。Windows 开发版和安装版均需验证加密可用性，不允许失败时降级为明文保存。

用户级加密的数据复制到其他 Windows 用户或机器后可能无法解密：数据库历史可以迁移，凭据需要重新填写。普通备份包含密文，不提供明文密钥导出。

## 6. 完成标准与实施边界

完成标准：CommentPilot 品牌、可配置多模型、加密持久化 Key、SQLite 历史、旧数据迁移、原监听行为回归和 Windows 安装包均通过验证。运行中的旧服务与已有数据先保全，再在必要时执行受控切换。

本轮不引入云数据库、多用户权限系统或平台官方接口，不要求用户另装数据库。本地模型服务由用户安装或提供地址；程序负责连接和诊断，不自动下载大型模型。缺少真实服务、账户权限或凭据时，准确报告验证边界，不声称已经真实跑通。

每阶段结束更新此文档勾选状态和验证结果。发现实现依赖时可调整内部顺序，无需为常规技术选择重新征求确认。

## 7. 实施结果

- 已完成品牌、多模型连接、加密凭据、SQLite 历史、界面及安装包。为兼容升级保留旧安装标识，旧用户数据目录继续沿用。
- 数据库采用 node:sqlite；开发 Node 26.7.0 与 Electron 内置 Node 24.22.0 均验证通过。配置与密文合并存于 model_connections，应用设置在 app_state，评论、调用、发送及作品版本采用独立表。
- 36 项单元测试、浏览器模拟测试、UI 与重启集成测试通过。实际旧数据副本 14 条记录迁移成功，重复启动无重复。
- 打包程序与安装后程序的 Chromium、OCR、SQLite、DPAPI 均通过。旧版覆盖升级与卸载通过，18 个打包源码文件一致性及私有路径排除检查通过。
- 云供应商协议采用模拟测试，未持真实 Key 逐家调用；本轮未在真实抖音账号发送测试回复。Codex 客户端/CLI 订阅登录不在本轮范围。
- 新版后端已启动于 http://127.0.0.1:3210，监听暂停。旧版内存 Key 需首次在模型连接中保存，之后加密持久保留。
