任务配置

默认仅生成草稿。自动模式每轮处理一条新评论。首次读取的可见评论也会进入队列，请先人工检查。

浏览器页面选择器（需要实页校准）

默认选择器是候选值，尚未针对该作品验证。仅读取当前已加载评论，不会自动遍历历史。发送成功标记必须在原评论内定位到本次回复。

连接与运行

先保存配置。在程序浏览器中扫码登录，打开作品并展开评论区；支持独立作品页和带 modal_id 的主页弹窗。切换作品后点击“打开配置作品”，核对后重新确认。

联调诊断
点击“诊断评论页面”，查看评论匹配数量及前三条预览。测试 模型 会产生一次 API 调用。
